## 📈 RESUMEN EJECUTIVO DE ESTRATEGIA

### Audience Distribution (25 agentes = 100%)

- **Urgencia Crítica (5 agentes):** 20% - ROI altísimo, conversión 8-10/10
- **Investigación/Diagnóstico (4 agentes):** 16% - ROI medio, requiere educación
- **Adaptación/Cambio (4 agentes):** 16% - ROI medio, específico por cambio
- **Frustración/Recalcitrante (3 agentes):** 12% - ROI bajo-medio, requiere validación
- **Ideológica/Rechazo (2 agentes):** 8% - ROI muy bajo, requiere comunidad
- **Otros (7 agentes):** 28% - ROI variable

### Budget Allocation Recomendada

| GRUPO | % DE BUDGET | RAZÓN |
|---|---|---|
| Urgencia Crítica | 40% | 20% de audience genera 60%+ de ROI |
| Investigación | 25% | Medio ROI pero volume alto |
| Adaptación | 20% | Específico por contexto, resulta bien |
| Otros | 15% | Retargeting + experimentación |

### KPIs Principales a Trackear

- **CTR:** Debe variar 3-10% según grupo (urgencia > curiosidad)
- **Conversion Rate:** Debe variar 1-10% según grupo (urgencia 8-10%, curiosidad 1-3%)
- **Cost per Lead:** Debe variar $5-50 según grupo
- **Lead Quality:** Urgencia > Investigación > Otros
- **Time to Close:** Urgencia <7 días, Investigación 14-30 días

## CONCLUSIÓN

**Las 25 identidades no son 25 personas diferentes.**

**Son 25 MOTIVACIONES diferentes para el MISMO problema.**

Esto permite:

1. **Hipótesis de búsqueda específica:** Cada agente = búsqueda única
2. **Mensajería hiperplural:** Cada agente = mensaje diferente
3. **Timing específico:** Cada agente = momento diferente del funnel
4. **Objeción targeting:** Cada agente = objeción específica a superar
5. **Trigger específico:** Cada agente = disparador único de conversión

**Google Ads para acné NO es una campaña.**

**Son 25 micro-campañas simultáneas.**
